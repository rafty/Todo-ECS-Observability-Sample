# 前提
- `backend/`にSpring Bootアプリケーションが存在します。

以下の要件を満たしてください。

# 要件

- `backend/`のSpring Bootアプリケーションにログを仕込みたいです。
- 業務コードのlogやデバッグのログを出力する時は、slf4jを使うという説明がされました。
- log.info/warn/error を必要箇所に追加（業務イベント、異常系、重要状態遷移）
- log.info()などを使ってログを出力すると思いますが、ログを仕掛け方が重要かと思っています。
    - デバッグにも使える
    - プログラムエラーなどの情報も残したい
    - 監査ログも残したい (DBの監査、イベントログ)
    - 業務ログを残したい (「注文が作成された」「契約ステータスが変更された」「誰が承認した」など、業務上の証跡として残す)
    - 障害調査や運用確認のためのログ
- ログ設計はアプリケーション運用に重要なため、`docs/backend/` にログ設計ドキュメントを追加したいです。
- `backend/AGENTS.md` にも、ログ実装（SLF4J利用、レベル使い分け、機密情報非出力など）の方針を追記したいです。
- OTelは別要件で検討するので対象外
